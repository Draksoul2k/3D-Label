# 3D Roll Studio - Phần Mềm Thiết Kế & Mô Phỏng Cuộn Tem Nhãn 3D

Ứng dụng web thiết kế tem nhãn kỹ thuật và mô phỏng cuộn tem 3D tương tác chất lượng cao, tính toán chiều dài cuộn, số tem, thước đo kỹ thuật và xuất maket chuyên nghiệp.

## Tính Năng Chính
- **Mô phỏng 3D tương tác**: Xoay 360 độ, phóng to, thu nhỏ, điều chỉnh góc nhìn.
- **Thước đo kỹ thuật 3D**: Đo kích thước tem (W, H), bước nhảy hàng (Gap Y), khoảng cách biên (Gap X, Margin), đường kính lõi.
- **Bảng thông số đặt hàng kéo thả**: Tùy biến cỡ chữ, di chuyển linh hoạt, ẩn hiện các thuộc tính.
- **Xuất ảnh Maket 2 chế độ**:
  - Chế độ 1: Tải nguyên mô hình cuộn tem 3D.
  - Chế độ 2: Tải mô hình 3D kèm bảng thông số kỹ thuật (bố cục thông minh không che đè).
- **Bộ thiết kế 2D**: Thiết kế nội dung trực tiếp trên tem (Barcode, QR Code, Text, Hình ảnh...).

## Chạy Ứng Dụng Trực Tiếp (Local)
Mở file index.html trực tiếp bằng trình duyệt, hoặc chạy bằng Python:
`ash
python run_app.py
`
Sau đó truy cập: http://localhost:8080

## Chạy Online Với GitHub Pages
1. Vào mục **Settings** của repository trên GitHub.
2. Chọn **Pages** ở menu bên trái.
3. Tại phần **Branch**, chọn main (hoặc master) và bấm **Save**.
4. Website sẽ tự động hoạt động trực tuyến qua link GitHub Pages được cấp!
